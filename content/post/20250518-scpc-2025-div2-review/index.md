> 이 글은 2025년 5월 18일 Notion에 작성했던 후기를 복원한 글이다. 당시의 문장과 표현, 제출 코드까지 최대한 그대로 옮겼고 수식 표기만 LaTeX로 정리했다.

대회 정보는 [2025 SCSC 프로그래밍 경시대회 안내 페이지](https://scsc.dev/w/scpc2025)에서 확인할 수 있다.

## 시작 전

필자는 PS를 고등학교 1학년 여름방학이 끝난 직후, 2021년 8월 말에 시작했다. 마지막으로 PS를 진심으로 했던 시기는 2022년 4월로 **3년 전**이지만, 대회 직전 두 Codeforces Round Div.2에 참가하여 각각 4솔로 블루 퍼포먼스를 내었기 때문에 실력을 어느 정도 복구했다고 생각했다.

SCSC의 임원진으로 강제 납치를 당해 일하고 있는 현재, 인력 부족을 우려하여 언제라도 대회 참가를 취소하고 스태프로 뛸 의향이 있었다. ***초천재미소녀해커***라는 닉네임도 이 상황이 아니었다면 탄생하지 않았을 것이다.

기숙사에서 1시에 기상, 샤워를 한 뒤 트리플바카 쟈코티셔츠를 입고 방을 나갔다. 메가커피에서 아메리카노 2잔과 블루베리 요거트 스무디 1잔을 주문하여 1시 40분쯤에 대회장에 들어가게 되었다.

작년 SCPC 2024에 참가하는 것을 추천받아 Div.2로 신청을 넣었지만, 대회 당일 몸살로 참가를 취소해야만 했었기 때문에, 40등 이내 수상을 목표로 대회에 임했다.

(사실 Div.3급 실력이라고 생각하지만, [solved.ac](https://solved.ac/) Rating 제한에 당했다ㅠㅠ)

### A - AC (15m)

과거 코포에서 테케만 보고 3분컷을 한 적이 있어서 자신이 있었지만, WA 페널티를 감수하기 싫어 하지 않았다.

다시 문제를 보자마자 바로

\[
7 \times (\text{number of faces})
\]

가 답이라는 걸 캐치하고 면 수를 구하기 시작했다. 최대를 구한 뒤 반전하면 최소가 나오기 때문이다. 처음에는 전체에서 가려진 면을 빼는 것을 목표로 잡고 식을 세워, 면의 수가

\[
\frac{2n^3+15n^2+13n}{12}
\]

라는 결과를 얻었다. 하지만 \(n=2\)를 대입하니 \(105\)와는 다른 값이 나와 당황하던 찰나, 보이는 면을 그냥 세면

\[
5 \times \sum_{k=1}^{n} k
\]

라는 걸 깨닫고 바로 풀었다.

접근만 잘 했어도 퍼솔각이 보였기에 아쉽게 느껴졌다. (15m)

**Code — \(\mathcal{O}(1)\)**

```cpp
#include<bits/stdc++.h>
using namespace std;

typedef long long ll;
typedef pair<ll,ll> pii;

#define fastio ios::sync_with_stdio(0);cin.tie(0);cout.tie(0);

ll v[200001];

void init()
{
    for(int i=1;i<=2025;i++) v[i]=v[i-1]+i;
}


int main()
{
    ll n;
    cin>>n;

    init();

    cout<<5*v[n]*7;
}
```

### B - AC+2 (96m)

15m이나 걸려 A를 해결한 후 B를 보자마자 [BOJ 16120 PPAP](https://www.acmicpc.net/problem/16120) 문제가 생각나 과거 작성하였던 \(\mathcal{O}(n)\) 코드를 수정해 제출했다. 하지만 앞부터 greedy하게 `HOH`를 제거하는 방식은 옳은 풀이가 아니었다.

DFS로 탐색하면 당연하게도 시간이 초과됐다. \(\mathcal{O}(n)\)에 해결할 수 있는 괄호 느낌이 났지만 아이디어가 생각나지 않아 스코어보드를 보고 I번으로 넘어갔다. (18m)

F를 붙들다 68m째에 다시 돌아와, 괄호 문제라고 가정하고 `O`의 위치와 `X`의 개수에 초점을 맞추어 풀이법을 생각했다. \(n=3k\)라 할 때 \(2k\)개의 `X`와 \(k\)개의 `O`가 존재한다. 정가운데의 `O`를 기준으로 좌우 괄호의 개수는 \(k\)개로 똑같다.

그렇기에 `O`와 `X`의 개수를 세면서 앞부터 쭉 밀다가 정가운데 `O`를 지난 후에는, `X`를 만날 때마다 `O`의 개수를 하나씩 빼 마이너스가 되지 않도록 괄호처럼 처리하면 된다. (92m)

다 풀은 줄 알았지만, 막상 제출하니 틀렸다. `O`가 `X`보다 많아질 경우에도 종료시켜야 하는 반례를 세지 않았기 때문인데, 이것만 바꿔서 내니 AC를 무난하게 받았다. (96m)

**Code — \(\mathcal{O}(n)\)**

```cpp
#include<bits/stdc++.h>
using namespace std;

typedef long long ll;
typedef pair<ll,ll> pii;

#define fastio ios::sync_with_stdio(0);cin.tie(0);cout.tie(0);


int main()
{
    ll n;
    cin>>n;

    string c;
    cin>>c;

    if(n%3){cout<<"mix"; return 0;}

    ll x=n/3;
    ll hcnt=0;
    ll ocnt=0;

    bool flag=0;
    ll diff=0;

    for(int i=0;i<n;i++)
    {
        if(c[i]=='O')
        {
            diff++;
            ocnt++;
        }

        if(c[i]=='H')
        {
            hcnt++;

            if(hcnt>x)
            {
                if(diff) diff--;
                else {cout<<"mix"; return 0;}
            }
        }

        if(ocnt>hcnt){cout<<"mix"; return 0;}
    }

    if(diff==0 && ocnt*2==hcnt) cout<<"pure";
    else cout<<"mix";
}
```

### G - WA+3

5분 동안 잠깐 고민해 아이디어를 떠올렸다. 두 차의 위치를 \(pos_1\) 및 \(pos_2\)로 구분하고 오른쪽으로 갈 때마다 \(+1\), 위로 갈 때마다 \(-1\)로 계산해

\[
\lvert pos_1-pos_2\rvert+1
\]

이라고 생각했다. 4개의 테스트케이스를 모두 맞추기 위해 \(pos_1=pos_2\)가 될 때의 예외 케이스를 생각해 유사찍맞을 시도했으나 틀렸다. (106m)

이후 Prefix Sum을 사용하는 아이디어로 \(\mathcal{O}(n)\) 구현을 시도했지만 실패했다. 대회가 끝나고 출제자 및 에디토리얼 편집자 `ohwphil`님이 내 아이디어가 맞다는 걸 다시 확인시켜 주면서 현타가 더 왔다.

### I - AC (22m)

19m에 문제를 보자마자 바로 아이디어가 떠올랐고, 수학적으로 증명 유사한 것까지 끝냈다. 구현해서 제출하니 바로 맞았다. (22m)

풀이에서는

\[
xy=n
\]

을 만족하는 \(x,y\) 중 \(x+y\)를 최소로 만들어야 한다. \(\sqrt{n}\)에서 1씩 빼 가다 \(n\)의 약수가 될 때의 값이 \(x\), \(\frac{n}{x}=y\)가 된다. 이후 \(y+1\)개의 노드를 왼쪽으로 쭉 연결한 뒤, 위에서부터 순서대로 \(x-1\)개의 리프 노드를 오른쪽 방향으로 붙여 주면 된다.

**Code — \(\mathcal{O}(n)\)**

```cpp
#include<bits/stdc++.h>
using namespace std;

typedef long long ll;
typedef pair<ll,ll> pii;

#define fastio ios::sync_with_stdio(0);cin.tie(0);cout.tie(0);


int main()
{
    ll n;
    cin>>n;

    ll x=1;

    for(int i=sqrt(n);i>=1;i--)
    {
        if(n%i==0)
        {
            x=i;
            break;
        }
    }

    ll y=n/x;

    cout<<(x+y)<<"\n";

    if(x>y) swap(x,y);

    for(int i=1;i<=y;i++) cout<<i<<" "<<i+1<<"\n";
    for(int i=1;i<=x-1;i++) cout<<i<<" "<<i+y+1<<"\n";
}
```

## 여담

- F 풀었으면 수상이다.
- 대회장에 들어가 심리적으로 편한 맨 뒷자리가 비어 있는 것을 보고 자리를 잡았는데, 마침 오른쪽에 **Lulusphere**가 앉아 있어 인사를 나누었다. 루루 넘 인싸임.
- 왼쪽에는 사운드 볼텍스 장패드를 들고 와 눈길을 끌게 된 참가자가 있었는데, 그 정체는 바로 **toycartoon**이었다! 대회가 끝난 이후에는 바로 앞자리에 있던 **your0501**, 토카를 찾아온 **cywohoy(종이)**도 만나게 되었다.
- 작년 서울대학교에 입학해 만나 밥을 사 주셨던 **ohwphil**님의 후광이 오늘따라 대단해 보였다. SCSC 25학번으로 들어와 만나게 된 **lumitt(니은), Lulusphere** 또한 만나게 되었다. 그와중에 나만 수상 실패한 거 뭐지.
- 뒤풀이를 가서 같은 임원진인 **Stork**와 밥을 먹었다. 그 뒤 인터넷 친구들과 친목을 나누다, 대회 결과에서도 옆자리고 앉아 있던 자리도 옆자리였던 **aerae**님의 권유로 술배를 뜨게 되었다.
- 대회 참여를 위해 과외까지 뺀 이상, 뒤풀이가 끝나고 코포를 치기 위해 기숙사로 가는 막차를 잡으러 취한 상태로 길을 뛰어가는 무단횡단을 했다.
- 많은 분들이 대회 이름을 SCSC로 알고 계시는데, SCSC는 동아리 이름이고 SCSC에서 주최하는 대회의 이름은 SCPC이다. 명명자에게 물어본 결과 동명의 대회 SCPC가 있지만 알빠노라고 한다.
